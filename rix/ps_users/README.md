# rix/ps_users

All accounts in the ps-users group, including rixopr, can edit the code here.
This folder is for science-controlled code to be included in hutch-python.
It should not refer to or link to code elsewhere in the filesystem.
If more code should be included, it needs to be a python module.

The data symbolic link is located in the rix opr's home directory.
It is meant to include calibration data and similar
that should not be committed as code.
